# Mutual Fund Analytics

## Project Overview

Mutual fund data analysis using Python, Pandas, MySQL, SQL, and visualization tools.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib, Seaborn, and Plotly
- MySQL
- Jupyter Notebook
- Git

## Project Structure
- data/raw/
- data/processed/
- notebooks/
- sql/
- dashboard/
- reports/

## SQL Analyses
1. Fund-house transaction analysis
2. Transaction type analysis
3. Monthly transaction analysis
4. Age-group analysis
5. State-wise analysis
6. Payment mode and KYC analysis
7. Fund category analysis
8. Top 10 schemes analysis
9. Investor transaction frequency
10. SIP versus lumpsum by age group

## Data Privacy
Do not publish credentials or sensitive investor-level information.

## Project Status
Initial data ingestion and 10 SQL analyses are complete. Dashboard development and final reporting remain.
